# CLI 工具速查手册（CLI_tools）

> [返回项目与领域实践](../../README.md)
>
> 沉淀日常开发中高频使用的命令行效率工具，每份文档聚焦**工具定位、核心特点、常用命令速查与常见使用流程**，方便随时翻查与新环境快速配置。

## 工具总览

| 工具 | 核心定位 | 一句话特点 | 文档入口 |
| :--- | :--- | :--- | :--- |
| **Git** | 分布式版本控制系统 | 轻量分支 + 四区模型 + `reflog` 后悔药，研发协作与代码溯源底座 | [git.md](git.md) |
| **Oh My Zsh** | Zsh 配置与插件管理框架 | 开箱即用的插件生态（自动建议/语法高亮/Git 短别名）与主题美化 | [oh-my-zsh.md](oh-my-zsh.md) |
| **tldr / tealdeer** | 社区极简命令示例速查工具 | 用 5~8 条高频示例替代冗长 `man` 手册，`tealdeer` 实现毫秒级离线响应 | [tldr-tealdeer.md](tldr-tealdeer.md) |
| **just** | 项目级命令运行器（待补充） | 类似 Makefile 的现代任务脚本工具 | `just/`（待补充） |

## 按日常诉求快速定位

- **提交代码、切分支、变基整理历史、误操作回滚** → [git.md](git.md)
- **新机/容器配终端、查 Git 短别名（`gst`/`gsw`）、排查终端启动慢** → [oh-my-zsh.md](oh-my-zsh.md)
- **忘记 `tar`/`find`/`rsync`/`git` 具体参数，想 3 秒看真实示例** → [tldr-tealdeer.md](tldr-tealdeer.md)

## 三者协同效率流

在日常终端中，三者天然互补：**Oh My Zsh** 负责提供智能补全、语法高亮和 `git` 插件短别名（日常敲命令省一半按键）；**Git** 负责代码版本流转与多人协作；遇到不熟的原生命令或冷门参数时，直接 `tldr <cmd>`（由 **tealdeer** 驱动）3 秒查到可复制示例，无需翻阅上千行 `man` 手册。
